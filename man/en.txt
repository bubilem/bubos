#### ls
NAME
    ls - list directory contents
SYNOPSIS
    ls [OPTION]... [FILE]...
DESCRIPTION
    Lists files and directories. Without arguments it lists the current directory.
OPTIONS
    -a   show hidden files too (names starting with a dot)
    -A   like -a, but without . and ..
    -l   long format: permissions, owner, group, size, date
    -h   human-readable sizes (with -l)
    -R   list subdirectories recursively
    -d   list the directory itself, not its contents
    -t   sort by modification time, newest first
    -S   sort by size, largest first
    -r   reverse the order
    -F   append / to directories, * to executables, @ to links
EXAMPLES
    ls -la ~          all files in the home directory, in detail
    ls -lh /etc       readable sizes
SEE ALSO
    tree, find, cd

#### cd
NAME
    cd - change the working directory
SYNOPSIS
    cd [DIRECTORY]
DESCRIPTION
    Without arguments goes to the home directory. "cd -" returns to the previous directory.
    ".." is the parent directory, "." the current one, "~" your home directory.
EXAMPLES
    cd /etc           absolute path (starts with /)
    cd ../Documents   relative path
SEE ALSO
    pwd, ls

#### pwd

SYNOPSIS

SEE ALSO

#### cat
NAME
    cat - concatenate files and print them
SYNOPSIS

DESCRIPTION

#### find
NAME
    find - search for files in a directory hierarchy
SYNOPSIS
    find [PATH...] [EXPRESSION]
DESCRIPTION
    Walks the directories and prints (or acts on) the entries that match all the tests.
EXPRESSION
    -name PATTERN    name matches the pattern (quote it: "*.txt")
    -iname PATTERN   the same, ignoring case
    -type f|d|l      file, directory, link
    -empty           empty files or directories
    -maxdepth N      descend at most N levels
    -mindepth N      skip the first N levels
    ! TEST           negate the test
    -print           print the path (default)
    -delete          delete the matches
    -exec CMD {} ;   run CMD for every match ({} is the path)
EXAMPLES
    find . -name "*.c"
    find ~ -type f -exec ls -l {} ;

#### chmod
NAME
    chmod - change file permissions
SYNOPSIS
    chmod [-R] MODE FILE...
DESCRIPTION
    MODE is either octal (755: owner rwx, group r-x, others r-x; r=4, w=2, x=1)
    or symbolic: who (u=user, g=group, o=others, a=all) + operator (+, -, =) + rwx.
OPTIONS
    -R   apply to directories recursively
EXAMPLES
    chmod 644 notes.txt
    chmod u+x script.sh
    chmod go-rwx secret.txt
SEE ALSO
    chown, ls -l

#### chown

DESCRIPTION
    Only root may change the owner. Use sudo.
EXAMPLES

#### grep
NAME
    grep - print lines that match a pattern
SYNOPSIS
    grep [OPTION]... PATTERN [FILE]...
DESCRIPTION
    Searches for PATTERN (a basic regular expression) in the files or in standard input.
    Quote the pattern so the shell does not interpret it.
OPTIONS
    -i   ignore case
    -v   invert: print lines that do NOT match
    -n   show line numbers
    -c   only count matching lines
    -l   only print names of files with a match
    -r   search directories recursively
    -E   extended regular expressions (+ ? | () {} without backslashes)
    -F   fixed string, not a regular expression
    -w   match whole words only
    -x   match whole lines only
    -o   print only the matching part
    -q   quiet, only set the exit status
REGULAR EXPRESSIONS
    .      any character          ^   start of line        $   end of line
    *      repeat 0 or more times [abc]  one of a, b, c    [^abc] none of them
    [[:digit:]] a digit           \< \>  word boundaries    \| alternation (-E: |)
EXAMPLES
    grep -n ERROR log.txt
    grep -E "^(Anna|Boris)" studenti.csv
    grep -rl "main" projekt/
SEE ALSO
    find, cut

#### cut
NAME
    cut - remove sections from each line
SYNOPSIS
    cut -d DELIM -f LIST [FILE]...
    cut -c LIST [FILE]...
OPTIONS
    -d   field delimiter (default: tab)
    -f   fields to keep: 1,3  or 2-4  or 2-
    -c   characters to keep
    -s   skip lines without the delimiter
EXAMPLES
    cut -d';' -f1,3 studenti.csv
    cut -d: -f1 /etc/passwd

#### tr
NAME
    tr - translate or delete characters
SYNOPSIS
    tr [-dsc] SET1 [SET2]
DESCRIPTION
    Reads standard input and replaces characters of SET1 with the corresponding characters of SET2.
    Sets can contain ranges (a-z) and classes ([:upper:], [:digit:] ...).
OPTIONS
    -d   delete characters of SET1
    -s   squeeze repeated characters
    -c   complement SET1
EXAMPLES
    echo hello | tr a-z A-Z
    tr -d '\n' < file.txt

#### echo

#### su
NAME
    su - switch user
SYNOPSIS
    su [-] [USER]
DESCRIPTION
    Starts a shell as another user (default root); asks for that user's password unless you are root.
    With "-" a full login shell is started (home directory, fresh environment). Leave with exit.
EXAMPLES
    su -
    su - bob

#### sudo
NAME
    sudo - run a command as another user (root)
SYNOPSIS
    sudo [-u USER] COMMAND [ARGUMENT]...
    sudo -i | -s
DESCRIPTION
    Allowed only for members of the group sudo. Asks for YOUR password (remembered for 5 minutes).
OPTIONS
    -u   run as this user instead of root
    -i   login shell as root
    -s   shell as root
    -k   forget the remembered password
EXAMPLES
    sudo cat /etc/shadow
    sudo useradd -m alice

#### useradd
NAME
    useradd - create a new user
SYNOPSIS
    useradd [-m] [-s SHELL] [-G GROUPS] [-c COMMENT] LOGIN
DESCRIPTION
    Root only. The user is added to /etc/passwd, /etc/group and /etc/shadow.
    The new account has no password yet - set one with passwd.
OPTIONS
    -m   create the home directory
    -s   login shell (default /bin/bash)
    -G   additional groups, comma separated
EXAMPLES
    sudo useradd -m -G sudo alice
    sudo passwd alice

#### ls
NAME
    ls - list directory contents
SYNOPSIS
    ls [OPTION]... [FILE]...
DESCRIPTION
    Lists files and directories. Without arguments it lists the current directory.
OPTIONS
    -a   show hidden files too (names starting with a dot)
    -A   like -a, but without . and ..
    -l   long format: permissions, owner, group, size, date
    -h   human-readable sizes (with -l)
    -R   list subdirectories recursively
    -d   list the directory itself, not its contents
    -t   sort by modification time, newest first
    -S   sort by size, largest first
    -r   reverse the order
    -F   append / to directories, * to executables, @ to links
EXAMPLES
    ls -la ~          all files in the home directory, in detail
    ls -lh /etc       readable sizes
SEE ALSO
    tree, find, cd

#### cd
NAME
    cd - change the working directory
SYNOPSIS
    cd [DIRECTORY]
DESCRIPTION

    ".." is the parent directory, "." the current one, "~" your home directory.
EXAMPLES
    cd /etc           absolute path (starts with /)
    cd ../Documents   relative path

#### find
NAME
    find - search for files in a directory hierarchy
SYNOPSIS
    find [PATH...] [EXPRESSION]
DESCRIPTION
    Walks the directories and prints (or acts on) the entries that match all the tests.
EXPRESSION
    -name PATTERN    name matches the pattern (quote it: "*.txt")
    -iname PATTERN   the same, ignoring case
    -type f|d|l      file, directory, link
    -empty           empty files or directories
    -maxdepth N      descend at most N levels
    -mindepth N      skip the first N levels
    ! TEST           negate the test
    -print           print the path (default)
    -delete          delete the matches
    -exec CMD {} ;   run CMD for every match ({} is the path)
EXAMPLES
    find . -name "*.c"
    find ~ -type f -exec ls -l {} ;

#### chmod

#### grep
NAME
    grep - print lines that match a pattern
SYNOPSIS
    grep [OPTION]... PATTERN [FILE]...
DESCRIPTION
    Searches for PATTERN (a basic regular expression) in the files or in standard input.
    Quote the pattern so the shell does not interpret it.
OPTIONS
    -i   ignore case
    -v   invert: print lines that do NOT match
    -n   show line numbers
    -c   only count matching lines
    -l   only print names of files with a match
    -r   search directories recursively
    -E   extended regular expressions (+ ? | () {} without backslashes)
    -F   fixed string, not a regular expression
    -w   match whole words only
    -x   match whole lines only
    -o   print only the matching part
    -q   quiet, only set the exit status
REGULAR EXPRESSIONS
    .      any character          ^   start of line        $   end of line
    *      repeat 0 or more times [abc]  one of a, b, c    [^abc] none of them
    [[:digit:]] a digit           \< \>  word boundaries    \| alternation (-E: |)
EXAMPLES
    grep -n ERROR log.txt
    grep -E "^(Ada|Alan)" studenti.csv
    grep -rl "main" projekt/
SEE ALSO
    find, cut

#### awk
NAME
    awk - simple language for processing tables and text
SYNOPSIS
    awk [-F SEP] [-v VAR=VALUE] 'PROGRAM' [FILE]...
DESCRIPTION
    A program consists of rules "pattern { action }". The action runs for every line matching the pattern.
    $1, $2 ... are columns, $0 the whole line, NF the number of columns, NR the line number.
    BEGIN { } runs before reading, END { } after everything has been read.
    Supports variables, arrays, if/while/for, printf and the functions length, substr, index, split,
    sub, gsub, toupper, tolower, int, sqrt.
EXAMPLES
    awk '{print $1}' students.txt
    awk -F';' '$3 > 80 {print $1}' students.csv
    awk '{s += $2} END {print s}' points.txt

#### break continue
NAME
    break, continue - leave a loop / skip to the next iteration
SYNOPSIS
    break [N]
    continue [N]
DESCRIPTION
    Used inside for, while and until. break ends the loop, continue skips the rest of the body and goes on
    with the next iteration. The number N says how many nested loops are affected (break 2 also ends the outer loop).
EXAMPLES
    for i in 1 2 3 4; do [ $i -eq 3 ] && break; echo $i; done

#### return
NAME
    return - leave a function with an exit status
SYNOPSIS
    return [N]
DESCRIPTION
    Without a number it returns the status of the last command. Zero means success, anything else an error;
    the status of the function is then in $? and can be used in if or &&.
EXAMPLES
    exists() { [ -e "$1" ] || return 1; echo "yes"; }

#### shift
NAME
    shift - shift the positional parameters of a script or function
SYNOPSIS
    shift [N]
DESCRIPTION
    Drops the first parameter: $2 becomes $1, $3 becomes $2 and so on; $# gets smaller.
    Useful for processing all arguments in a loop while [ $# -gt 0 ].
EXAMPLES
    while [ $# -gt 0 ]; do echo "$1"; shift; done

#### local
NAME
    local - a variable valid only inside a function
SYNOPSIS
    local NAME[=VALUE]...
DESCRIPTION
    When the function ends the variable gets its previous value back, so the function does not overwrite variables of the script.
EXAMPLES
    sum() { local s=0; for n in "$@"; do s=$((s + n)); done; echo $s; }

#### :
NAME
    : - do nothing, successfully
SYNOPSIS
    :
DESCRIPTION
    The empty command. Useful as the body of a branch that should do nothing, or as an endless condition: while :; do ...; done.

#### let
NAME
    let - evaluate an arithmetic expression
SYNOPSIS
    let EXPRESSION...
DESCRIPTION
    Integer arithmetic with variables: + - * / % ** and parentheses, comparisons, && ||, assignment (=, +=) and ++/--.
    $(( … )) and ((…)) work the same way. The exit status is 0 if the result is non-zero.
EXAMPLES
    let "x = 2 * 3"; echo $x
    echo $((x + 1))
    ((i++))

#### [[
NAME
    [[ - extended conditional expression
SYNOPSIS
    [[ EXPRESSION ]]
DESCRIPTION
    Like test and [, but more convenient: variables need no quotes, the right side of == is a pattern with wildcards,
    =~ matches a regular expression and && and || can be written directly inside.
EXAMPLES
    [[ $file == *.txt ]] && echo text
    [[ -f a.txt && -r a.txt ]] && echo readable
    [[ $x =~ ^[0-9]+$ ]] && echo number


#### cowsay
NAME
    cowsay - a cow (or a penguin) says what you send it
SYNOPSIS
    cowsay [-f cow|tux] [-W WIDTH] [TEXT...]
DESCRIPTION
    Without text it reads standard input, so it works nicely in a pipe: fortune | cowsay.
EXAMPLES
    cowsay Hello, world!
    cowsay -f tux Linux rulez

#### fortune
NAME
    fortune - print a random bit of IT wisdom
SYNOPSIS
    fortune
DESCRIPTION
    Picks a different quote each time. Together with cowsay it forms a classic pair.
EXAMPLES
    fortune
    fortune | cowsay

#### sl
NAME
    sl - a train for those who mistype ls
SYNOPSIS
    sl
DESCRIPTION
    A deliberate pun: sl is ls with swapped letters. The correctly typed command is ls.

#### factor
NAME
    factor - factor numbers into primes
SYNOPSIS
    factor [NUMBER...]
DESCRIPTION
    Without arguments it reads numbers from standard input. The output looks like NUMBER: factor factor ...
EXAMPLES
    factor 42
    seq 10 | factor
